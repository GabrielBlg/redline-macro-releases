# Redline Macro

Fast, clean macros for Windows: edits, builds, movement and your own recorded sequences, each on its own key with timing you control.

**[⬇ Download the latest version](https://github.com/GabrielBlg/redline-macro-releases/releases/latest/download/RedlineMacroApp-win-Setup.exe)**

## Getting started

1. Buy a licence at **[redline-macro.pages.dev](https://redline-macro.pages.dev)**. Your key arrives by email.
2. Download and run `RedlineMacroApp-win-Setup.exe`.
3. Open Redline Macro and paste your licence key.

Redline Macro updates itself: when a new version is out, the app asks if you want to install it.

## Requirements

- 64-bit Windows 10 or 11
- An internet connection (the licence is checked online)
- .NET 10 Desktop Runtime (the installer adds it if it's missing)
